Usage

Add two files to your project.

<link rel="stylesheet" href="tokens.css">
<link rel="stylesheet" href="components.css">

Or import into your CSS:

@import url("tokens.css");
@import url("components.css");

Then use the component classes in your HTML. All tokens are available as CSS custom properties on :root — override any value to customize the theme.

:root {
  --sr-accent: #0891b2;   /* cyan accent instead of violet */
  --sr-radius-lg: 12px;   /* tighter corners */
}
